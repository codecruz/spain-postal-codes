API

Todas las rutas son ficheros JSON estáticos servidos por GitHub Pages, con CORS abierto. Un código o municipio inexistente devuelve 404.

RutaContenido
v1/cp/{cod_postal}.jsonMunicipios que sirve un código postal
v1/municipios/{id}.jsonUn municipio (código INE) y sus códigos postales
v1/municipios.jsonTodos los municipios, útil para autocompletar
v1/provincias.jsonLas 52 provincias con sus totales
v1/provincias/{id}.jsonUna provincia con sus municipios y códigos
v1/meta.jsonPeriodo de los datos, licencia y totales
 
const res = await fetch("https://codecruz.github.io/spain-postal-codes/v1/cp/41700.json");
const { municipios } = await res.json();
// [{ id: "41038", nombre: "Dos Hermanas", provincia_id: "41", provincia: "Sevilla" }]

Paquete npm

Los mismos datos, empaquetados para usarlos sin red, en Node o en el navegador:

npm install spain-postal-codes
import { lookup, searchMunicipios } from "spain-postal-codes";

lookup("28001");             // [{ id: "28079", nombre: "Madrid", ... }]
searchMunicipios("alcala");  // sin distinguir acentos ni mayúsculas

Librería PHP

La misma API para PHP 8.1+, sin dependencias (código fuente):

composer require codecruz/spain-postal-codes
use Codecruz\SpainPostalCodes\PostalCodes;

PostalCodes::lookup('28001')[0]->nombre;  // "Madrid"
